CountVectorsFeaturizer — это компонент Rasa, который преобразует текст в числовые векторы на основе частоты слов (Bag of Words) или N-грамм. Это один из ключевых этапов обработки текста, который помогает модели учитывать частоту и последовательности слов. Давайте разберем, как он работает, какие настройки доступны и как работают N-граммы.

# 1. Что делает CountVectorsFeaturizer?

Bag of Words (BoW):

 - Текст разбивается на слова (токены).
 - Для каждого слова подсчитывается, сколько раз оно встречается в тексте.
 - Создается вектор, где каждый элемент соответствует частоте определенного слова.

N-граммы:

 - Вместо отдельных слов учитываются последовательности из N слов (например, биграммы, триграммы).
 - Это помогает модели учитывать контекст и последовательности слов.

# 2. Как работают N-граммы?

N-грамма — это последовательность из N слов или символов.

Пример:
 - Текст: "Добрый день"
 - Униграммы (1-граммы): ["Добрый", "день"]
 - Биграммы (2-граммы): ["Добрый день"]
 - Триграммы (3-граммы): ["Добрый день"] (для коротких текстов триграммы могут не применяться).

N-граммы помогают модели учитывать контекст. Например, фраза "Добрый день" имеет другое значение, чем отдельные слова "Добрый" и "день".

# 3. Конфигурация CountVectorsFeaturizer

В Rasa CountVectorsFeaturizer можно настроить через конфигурацию в config.yml. Вот основные параметры:

```yaml
pipeline:
  - name: CountVectorsFeaturizer
    analyzer: "word"  # Анализировать по словам ("word") или символам ("char")
    min_ngram: 1      # Минимальная длина N-граммы
    max_ngram: 2      # Максимальная длина N-граммы
    max_features: 1000  # Максимальное количество признаков
    lowercase: True   # Приводить текст к нижнему регистру
    stop_words: None  # Список стоп-слов (например, ["и", "в", "на"])
    min_df: 1         # Минимальная частота слова для включения в признаки
    max_df: 1.0       # Максимальная частота слова для включения в признаки
```

Описание параметров:
 - analyzer: Анализировать текст по словам ("word") или символам ("char").
 - min_ngram: Минимальная длина N-граммы (например, 1 для униграмм).
 - max_ngram: Максимальная длина N-граммы (например, 2 для биграмм).
 - max_features: Максимальное количество признаков (слов или N-грамм).
 - lowercase: Приводить текст к нижнему регистру.
 - stop_words: Список стоп-слов, которые будут игнорироваться.
 - min_df: Минимальная частота слова для включения в признаки (например, 1 — слово должно встречаться хотя бы один раз).
 - max_df: Максимальная частота слова для включения в признаки (например, 1.0 — слово может встречаться в любом количестве документов).

# 4. Пример работы

Допустим, у нас есть тексты:

 - "Добрый день"
 - "Добрый вечер"

После обработки CountVectorsFeaturizer с min_ngram=1 и max_ngram=2:

 - Униграммы: ["добрый", "день", "вечер"]
 - Биграммы: ["добрый день", "добрый вечер"]

Векторы:
 - Для "Добрый день": [1, 1, 0, 1, 0] (униграммы: "добрый", "день"; биграмма: "добрый день").
 - Для "Добрый вечер": [1, 0, 1, 0, 1] (униграммы: "добрый", "вечер"; биграмма: "добрый вечер").

# 5. Как это влияет на модель?

Признаки, созданные CountVectorsFeaturizer, помогают модели учитывать частоту и последовательности слов.
Например, если в тексте часто встречается биграмма "добрый день", модель может использовать это для более точной классификации.

# 6. Рекомендации

Используйте min_ngram и max_ngram, чтобы настроить длину N-грамм. Например:

 - min_ngram=1, max_ngram=1: Только униграммы.
 - min_ngram=1, max_ngram=2: Униграммы и биграммы.

Если у вас много уникальных слов, увеличьте max_features, чтобы учесть больше признаков.
Используйте stop_words, чтобы исключить часто встречающиеся слова (например, "и", "в", "на").

# 7. Пример конфигурации

```yaml
pipeline:
  - name: WhitespaceTokenizer
  - name: RegexFeaturizer
  - name: LexicalSyntacticFeaturizer
  - name: CountVectorsFeaturizer
    analyzer: "word"
    min_ngram: 1
    max_ngram: 2
    max_features: 1000
    lowercase: True
    stop_words: ["и", "в", "на"]
    min_df: 1
    max_df: 1.0
  - name: DIETClassifier
```
